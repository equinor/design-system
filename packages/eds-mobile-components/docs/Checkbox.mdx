## Features

- The whole row is pressable, so pressing the label toggles the checkbox as well as the box.
- You own the checked state. Pressing the checkbox reports the new value, and you pass it back in.
- Shows a soft highlight while it is pressed.
- Without a label it becomes a round touch target, for lists and bulk selection headers.
- Reduces the contrast of the icon and the label when disabled.

## Usage

```bash
npm install @equinor/eds-mobile-components
```

```tsx
import { Checkbox } from '@equinor/eds-mobile-components'

const [checked, setChecked] = useState(false)

<Checkbox label="Accept terms" checked={checked} onPress={setChecked} />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `onPress` | `(checked: boolean) => void` | None | Callback method invoked when the user presses the checkbox. |
| `disabled` | `boolean` | `false` | Whether the checkbox is in its disabled state. |
| `checked` | `boolean` | `false` | Whether the checkbox should be in its checked state. |
| `indeterminate` | `boolean` | `false` | Whether the checkbox should be in its indeterminate state. Takes precedence over `checked`. |
| `label` | `string` | None | Label displayed next to the checkbox. When omitted, an `accessibilityLabel` must be provided for screen readers. |
| `accessibilityLabel` | `string` | None | Accessible name for screen readers. Required when `label` is not provided. |

## Examples

### States

A checkbox is checked, unchecked or indeterminate. Indeterminate takes precedence over `checked`.

```tsx
<Checkbox label="Unchecked" checked={false} onPress={setChecked} />
<Checkbox label="Checked" checked={true} onPress={setChecked} />
<Checkbox label="Indeterminate" indeterminate onPress={setChecked} />
```

### Selecting multiple options

Checkbox has no group wrapper, so keep the selected options in the parent screen's state.

```tsx
{options.map((option) => (
    <Checkbox
        key={option}
        label={option}
        checked={selected.includes(option)}
        onPress={() => toggle(option)}
    />
))}
```

### Indeterminate parent

Use `indeterminate` on a parent checkbox when only some of its children are selected. Screen readers hear it as mixed. `allChecked` and `setSelected` are `useState` values kept in the parent screen.

```tsx
<Checkbox
    label="All notifications"
    checked={allChecked}
    indeterminate={someChecked}
    onPress={() => setSelected(allChecked ? [] : options)}
/>
```

### Without label

Use this in multi-select lists and bulk selection headers, where the row or the column title already says what is being selected. Give it an `accessibilityLabel`, and it renders as a round touch target.

```tsx
<Checkbox
    checked={true}
    onPress={setChecked}
    accessibilityLabel="Select row"
/>
```

### Disabled

A disabled checkbox ignores presses and shows less contrast.

```tsx
<Checkbox label="Unavailable" checked={false} disabled />
<Checkbox label="Locked in" checked={true} disabled />
```

## Accessibility

- Checkbox sets the checkbox role automatically.
- It reports its state to screen readers as checked, unchecked or mixed (when indeterminate), together with whether it is disabled.
- The `label` is used as the accessible name unless `accessibilityLabel` is set.
- Always provide a `label` or an `accessibilityLabel`. A checkbox with neither has no name for screen readers.

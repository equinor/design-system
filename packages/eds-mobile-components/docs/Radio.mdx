## Features

- Lets the user choose exactly one option from a group, unlike Checkbox, which allows any number.
- The whole row is pressable, so pressing the label selects the radio as well as the circle.
- Shows a brief coloured highlight while pressed, the only visual reaction to a press. Selecting itself has no separate animation.
- Without a label it becomes a round touch target, for lists of options where the row already says what is being selected.
- Reduces the contrast of the icon and the label when disabled.

## Usage

```bash
npm install @equinor/eds-mobile-components
```

```tsx
import { Radio } from '@equinor/eds-mobile-components'

const [selected, setSelected] = useState('apples')

<Radio
  label="Apples"
  checked={selected === 'apples'}
  onPress={() => setSelected('apples')}
/>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `onPress` | `(checked: boolean) => void` | None | Callback method invoked when the user presses the radio button. |
| `disabled` | `boolean` | `false` | Whether the radio button is in its disabled state. |
| `checked` | `boolean` | `false` | Whether the radio button should be in its checked state. |
| `label` | `string` | None | Label displayed next to the radio button. When omitted, an `accessibilityLabel` must be provided for screen readers. |
| `accessibilityLabel` | `string` | None | Accessible name for screen readers. Required when `label` is not provided. |

## Examples

### Selecting from options

Radio has no group wrapper, so keep the selected option in the parent screen's state.

```tsx
{options.map((option) => (
    <Radio
        key={option}
        label={option}
        checked={selected === option}
        onPress={() => setSelected(option)}
    />
))}
```

### Preselected

Start the state at the option that should be selected when the screen first appears, for example `useState("Standard delivery")`, rather than leaving the group unselected.

```tsx
<Radio
    label="Standard delivery"
    checked={preselected === "Standard delivery"}
    onPress={() => setPreselected("Standard delivery")}
/>
<Radio
    label="Express delivery"
    checked={preselected === "Express delivery"}
    onPress={() => setPreselected("Express delivery")}
/>
```

### List row

Radio has no slot for extra detail, so wrap it in your own row and add a second piece of text next to it.

```tsx
<View style={{ flexDirection: "row", alignItems: "center", gap: 8 }}>
    <Radio
        label="Standard delivery"
        checked={preselected === "Standard delivery"}
        onPress={() => setPreselected("Standard delivery")}
    />
    <Typography>3 to 5 working days</Typography>
</View>
```

### Without label

Use this in lists of options where the row already says what is being selected. Give it an `accessibilityLabel`, and it renders as a round touch target.

```tsx
<Radio
    checked={isSelected}
    onPress={() => setIsSelected(true)}
    accessibilityLabel="Select option A"
/>
```

### Disabled

A disabled radio ignores presses and shows less contrast.

```tsx
<Radio label="Unavailable" checked={false} disabled />
<Radio label="Locked in" checked={true} disabled />
```

## Accessibility

- Radio sets the radio role automatically.
- It reports its checked and disabled state to screen readers.
- The `label` is used as the accessible name unless `accessibilityLabel` is set.
- Always provide a `label` or an `accessibilityLabel`. A radio with neither has no name for screen readers.

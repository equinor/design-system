## Features

- Draws an icon from the Material Community Icons set by `name`, and the `IconName` type lists the valid names.
- Takes its default size and colour from the EDS tokens, so the colour follows the colour scheme.
- Takes every React Native text prop too, such as `accessibilityLabel`, and passes it on to the icon.

## Usage

```bash
npm install @equinor/eds-mobile-components
```

```tsx
import { Icon } from '@equinor/eds-mobile-components'

<Icon name="home" />
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `number` | None | The size of the icon, in points. Defaults to the EDS icon size. |
| `name` | `IconName` | None | The name of the icon, from the Material Community Icons set. Required. |
| `color` | `string` | None | The colour of the icon. Defaults to the strong neutral text colour. |

Also accepts all React Native [`TextProps`](https://reactnative.dev/docs/text#props).

## Examples

### Sizes

Set `size` in points. Without it, the icon uses the EDS icon size.

```tsx
<Icon name="home" size={16} />
<Icon name="home" size={24} />
<Icon name="home" size={32} />
```

### Colors

Without `color`, the icon uses the strong neutral text colour, which follows the colour scheme. Set `color` to use another colour, and check its contrast against the background in both schemes.

```tsx
<Icon name="check-circle" />
<Icon name="check-circle" color="seagreen" />
```

### With label

Give an icon that carries meaning on its own an `accessibilityLabel`. Hide a decorative icon, which only repeats the text beside it, with `accessibilityElementsHidden`.

```tsx
<Icon name="alert-circle" accessibilityLabel="Warning" />
<Icon name="alert-circle" accessibilityElementsHidden />
```

## Accessibility

- Icon sets no accessibility props of its own. Anything you pass, such as `accessibilityLabel`, goes straight to the icon.
- An icon that carries meaning on its own, such as one inside an icon-only action, needs an `accessibilityLabel`.
- A decorative icon that only repeats the text beside it can be hidden from screen readers with `accessibilityElementsHidden`.
- The default colour is a text colour, so it meets the contrast of the surrounding text. A `color` you set yourself needs enough contrast against the background in both colour schemes.

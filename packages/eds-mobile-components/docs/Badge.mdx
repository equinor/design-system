## Features

- Short text or a number for indicating status or a count.
- Can sit on the trailing edge of a row or card, next to other components.
- Truncates to a single line.
- Solid and outlined badges are the same size, so switching between them does not shift the layout.

## Usage

```bash
npm install @equinor/eds-mobile-components
```

```tsx
import { Badge } from '@equinor/eds-mobile-components'

<Badge tone="success">Approved</Badge>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `string \| number` | None | The label text or number displayed inside the badge. Required. |
| `tone` | `'neutral' \| 'accent' \| 'success' \| 'info' \| 'warning' \| 'danger'` | `'neutral'` | Semantic colour tone. |
| `emphasis` | `'low' \| 'medium'` | `'low'` | Visual weight of the badge. |
| `variant` | `'solid' \| 'outlined'` | `'solid'` | Solid fill or outlined border. |

Also accepts all React Native [`ViewProps`](https://reactnative.dev/docs/view#props).

## Examples

### Tones

Pick the tone by meaning, not by colour: `success`, `warning` and `danger` for status, `info` for notes, `accent` for categories and `neutral` when the badge carries no status.

```tsx
<Badge tone="neutral">Neutral</Badge>
<Badge tone="accent">Accent</Badge>
<Badge tone="success">Success</Badge>
<Badge tone="info">Info</Badge>
<Badge tone="warning">Warning</Badge>
<Badge tone="danger">Danger</Badge>
```

### Emphasis

Use `low` in table cells and list rows. Switch to `medium` when the badge has to stand out, for example in a card header.

```tsx
<Badge tone="accent" emphasis="low">Low</Badge>
<Badge tone="accent" emphasis="medium">Medium</Badge>
```

### Outlined

Outlined swaps the fill for a border, which keeps a badge light on rows that already have a coloured background.

```tsx
<Badge tone="accent" variant="outlined" emphasis="low">Low</Badge>
<Badge tone="accent" variant="outlined" emphasis="medium">Medium</Badge>
```

### Numbers

Badge accepts a number as children, which suits counts.

```tsx
<Badge tone="danger">{3}</Badge>
<Badge tone="neutral" emphasis="medium">{42}</Badge>
```

## Accessibility

- Screen readers read the badge text automatically, so no extra setup is needed for basic use.
- Tone is not announced by screen readers. Avoid relying on colour alone to convey meaning, and pair the badge with a visible text label where possible.
- When additional context is needed beyond the badge text, pass `accessibilityLabel` directly to the Badge component:

```tsx
<Badge tone="success" variant="solid" accessibilityLabel="Status: Approved">Approved</Badge>
```

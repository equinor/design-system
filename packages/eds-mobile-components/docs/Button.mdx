## Features

- Can have an icon before the label, after it, or both.
- Changes its background while it is pressed.
- Dims its label and icons when disabled.
- Takes every React Native `PressableProps` too, such as `onPress` and `disabled`.
- Has an icon-only variant, `Button.Icon`, for compact actions. It takes the same `tone`, `size` and `variant`, and its own props are listed under Props.

## Usage

```bash
npm install @equinor/eds-mobile-components
```

```tsx
import { Button } from '@equinor/eds-mobile-components'

<Button label="Save" onPress={handleSave} />
```

## Props

Button has no props of its own.

### Button.Icon

Button.Icon has no props of its own.

## Examples

### Variants

Use the variant to show which action matters most. Primary is the default.

```tsx
<Button label="Primary" variant="primary" onPress={handlePress} />
<Button label="Secondary" variant="secondary" onPress={handlePress} />
<Button label="Ghost" variant="ghost" onPress={handlePress} />
```

### Tones

Use `tone` to signal the intent of an action. Every tone works with every variant.

```tsx
<Button label="Save" tone="accent" onPress={handlePress} />
<Button
    label="Cancel"
    tone="neutral"
    variant="secondary"
    onPress={handlePress}
/>
<Button label="Delete" tone="danger" onPress={handlePress} />
```

### With icons

Use `leadingIcon` to show an icon before the label and `trailingIcon` to show one after it.

```tsx
<Button label="Download" leadingIcon="download" onPress={handlePress} />
<Button label="Next" trailingIcon="arrow-right" onPress={handlePress} />
```

### Icon only

Use `Button.Icon` when a visible label would be redundant. `round` makes it a circle. It has no text, so always give it an `accessibilityLabel`.

```tsx
<Button.Icon
    name="close"
    accessibilityLabel="Dismiss"
    onPress={handlePress}
/>
<Button.Icon
    name="heart"
    round
    accessibilityLabel="Favourite"
    onPress={handlePress}
/>
```

### Disabled

A disabled button ignores presses and shows less contrast.

```tsx
<Button label="Unavailable" disabled />
```

## Accessibility

- Button sets the button role automatically.
- It reports its disabled state to screen readers.
- The `label` is the accessible name.
- Any `accessibilityState` you pass is merged with the built-in disabled state.
- `Button.Icon` has no text, so always give it an `accessibilityLabel`.

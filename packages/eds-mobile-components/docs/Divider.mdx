## Features

- Stretches to the full width of its container.
- Draws a thin line in the subtle border colour, so it separates content without competing with it.
- Has no margin of its own, so you set the space around it with `style`.

## Usage

```bash
npm install @equinor/eds-mobile-components
```

```tsx
import { Divider } from '@equinor/eds-mobile-components'

<Divider />
```

## Props

Divider has no props of its own.

## Examples

### Settings list

A Divider has no margin of its own, so pass `style` to set the space above and below it.

```tsx
<View style={{ flexDirection: "row", justifyContent: "space-between" }}>
    <Typography>Language</Typography>
    <Typography>English</Typography>
</View>
<Divider style={{ marginVertical: 16 }} />
<View style={{ flexDirection: "row", justifyContent: "space-between" }}>
    <Typography>Theme</Typography>
    <Typography>System</Typography>
</View>
```

### Between sections

Use a Divider to separate sections of a screen when the headings alone do not make the break clear enough.

```tsx
<Typography weight="bolder">Delivery</Typography>
<Typography>Orders placed before 14:00 ship the same day.</Typography>
<Divider style={{ marginVertical: 16 }} />
<Typography weight="bolder">Returns</Typography>
<Typography>You can return an item within 30 days.</Typography>
```

### Before the total

A Divider before a total shows that the last row sums up the ones above it.

```tsx
<View style={{ flexDirection: "row", justifyContent: "space-between" }}>
    <Typography>Coffee beans</Typography>
    <Typography>120 NOK</Typography>
</View>
<View style={{ flexDirection: "row", justifyContent: "space-between" }}>
    <Typography>Filter papers</Typography>
    <Typography>45 NOK</Typography>
</View>
<Divider style={{ marginVertical: 16 }} />
<View style={{ flexDirection: "row", justifyContent: "space-between" }}>
    <Typography weight="bolder">Total</Typography>
    <Typography weight="bolder">165 NOK</Typography>
</View>
```

## Accessibility

- Divider is hidden from screen readers and is not focusable, because it only separates content visually.
- It always stays hidden, even if you pass `accessible`.

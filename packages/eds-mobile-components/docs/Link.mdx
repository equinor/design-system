## Features

- Comes as a standalone link with its own touch target, or as an inline link that sits inside a sentence.
- Follows the Typography size scale, so a link can match the text around it.
- Changes colour while it is pressed.
- Can show an icon that marks a link opening outside the app.
- Shows a visited colour when you mark the link as visited. You track the visited state yourself.

## Usage

```bash
npm install @equinor/eds-mobile-components
```

```tsx
import { Link } from '@equinor/eds-mobile-components'

<Link onPress={handlePress}>Open documentation</Link>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | None | The link label. Required. |
| `onPress` | `TextProps["onPress"]` | None | Called when the link is pressed. |
| `variant` | `'standalone' \| 'inline'` | `'standalone'` | Visual variant. `standalone` has its own underline and a proper touch target. `inline` sits inside a sentence of text and renders as a Text element. |
| `size` | `LinkSize` | `'md'` | Font size, matching the Typography UI size scale. |
| `external` | `boolean` | `false` | Shows an external link icon alongside the text. |
| `visited` | `boolean` | `false` | Marks the link as previously visited. Consumer is responsible for tracking this state. |

## Examples

### Standalone

A standalone link is a button-sized touch target with its own underline. It is the default.

```tsx
<Link onPress={handlePress}>Open documentation</Link>
```

### Inline

Use `variant="inline"` to place a link inside a sentence. It renders as text, so it sits alongside the words around it.

```tsx
<Typography>
    Read the{" "}
    <Link variant="inline" onPress={handlePress}>
        full documentation
    </Link>{" "}
    for more details.
</Typography>
```

### Sizes

The size follows the Typography UI scale. Use it to match a link to the text it sits next to.

```tsx
<Link size="sm" onPress={handlePress}>
    Small
</Link>
<Link size="md" onPress={handlePress}>
    Medium
</Link>
<Link size="lg" onPress={handlePress}>
    Large
</Link>
```

### External

Set `external` to show an icon that tells the user the link opens outside the app.

```tsx
<Link external onPress={handlePress}>
    View on GitHub
</Link>
```

### Visited

Link does not remember being pressed. Keep that in your own state, as a real screen does with `useState`, and pass it as `visited`.

```tsx
<Link visited={visited} onPress={markVisited}>
    Open documentation
</Link>
```

## Accessibility

- Link sets the link role automatically, on both variants.
- The text of `children` is the accessible name, so it should make sense out of context. Write "Open the documentation", not "Click here".
- Link does not accept an `accessibilityLabel`, so the visible text has to carry the meaning.

# Icon

Icon renders an icon from `@equinor/eds-icons` as an SVG, on its own or next to text.

**Beta:** safe to adopt alongside EDS 1.0. The API may still change in small ways before EDS 2.0 becomes stable. See [About EDS 2.0](?path=/docs/eds-2-0-beta-about--docs) for what beta means.

## Features

- Is `--eds-spacing-xl` by default, the icon size in the EDS Assets Figma file, whatever the size of the text around it.
- Takes its size from the spacing token of the same name, so `size="md"` is the `spacing-md` variable bound in Figma.
- Follows the density of its parent element, so it grows or shrinks with `data-density`.
- Inherits the text colour through `currentColor`, so it matches the text it sits next to.
- Is sized by the component when used inside Button, Chip or a standalone Link, so the `size` prop has no effect there.

## Examples

### Explicit sizes


Each size is the spacing token of the same name. Without `size`, the icon is `xl`. To choose a size, use the spacing variable the icon is bound to in Figma. There is no fixed size per text size: Button pairs label md with `lg`, Chip and Link pair it with `md`.

| Size  | Token               | Comfortable |
|-------|---------------------|-------------|
| sm    | `--eds-spacing-sm`  | 12px        |
| md    | `--eds-spacing-md`  | 16px        |
| lg    | `--eds-spacing-lg`  | 20px        |
| xl    | `--eds-spacing-xl`  | 24px        |
| 2xl   | `--eds-spacing-2xl` | 28px        |
| 3xl   | `--eds-spacing-3xl` | 32px        |
| 4xl   | `--eds-spacing-4xl` | 40px        |
| 5xl   | `--eds-spacing-5xl` | 48px        |
| 6xl   | `--eds-spacing-6xl` | 64px        |
| 7xl   | `--eds-spacing-7xl` | 80px        |

### Inline with text

The icon size does not follow the text. Next to smaller text, set `size` to the spacing token the design uses. An inline icon is centred on the text.

### Densities

Set `data-density` on an ancestor. Every size, including the default, follows the spacing scale and changes with the density.

### Color

Icons use `currentColor` by default, so they take the colour of the surrounding text. To set a colour, pass a semantic icon token such as `var(--eds-icon-secondary)` to `color`, never a raw colour value.

### Inside components

Button, Chip and a standalone Link size the icons you pass them, so leave out `size`. The Button here sets `size="5xl"`, and the icon still follows the button.

### Decorative and semantic

Without `title` an icon is decorative and gets `aria-hidden`. With `title` it gets the `img` role and the title as its name. In an icon-only button, put the name on the button with `aria-label` and keep the icon decorative, so it is not read twice.

## Accessibility

- Without `title`, the icon is decorative. It gets `aria-hidden`, so screen readers skip it. Use this when visible text next to it says the same.
- With `title`, the icon gets the `img` role and its title as accessible name. Use this when the icon carries meaning that no text gives.
- Icon is not focusable and has no keyboard behaviour.
- In an icon-only button, the button carries the name with `aria-label`, and the icon stays decorative. A `title` on the icon as well would be read twice.
- Colour alone does not reach a screen reader, so an icon whose colour shows a state, such as an error, needs text or a `title` saying so.

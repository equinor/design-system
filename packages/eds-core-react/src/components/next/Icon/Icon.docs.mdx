# Icon

Renders an SVG symbol from `@equinor/eds-icons`. Sizes itself from the surrounding typography by default, so icons stay visually matched to the text they sit beside.

**⚠️ Beta.** This component is under active development and may have breaking changes.

## Features

- Ten sizes, `xs` through `6xl`, mapped to the `--eds-sizing-icon-*` tokens.
- Automatic sizing from a parent `Typography`, falling back to `1.5em` when no tokens apply.
- Sizing responds to the `data-density` ancestor attribute.
- Colour inherited from `currentColor`.
- Optional `title` that renders the icon as a labelled image instead of a decorative one.

## Usage

```bash
npm install @equinor/eds-core-react@beta
```

```tsx
import { Icon } from '@equinor/eds-core-react/next'
import { TypographyNext as Typography } from '@equinor/eds-core-react'
import { save } from '@equinor/eds-icons'

// Auto-sized from Typography
<Typography size="md">
  Click <Icon data={save} /> to save
</Typography>

// Explicit size for standalone usage
<Icon data={save} size="lg" />
```

## Sizing

Size is resolved in this order, highest priority first:

1. An explicit `size` prop, which uses the `--eds-sizing-icon-*` tokens.
2. A parent `Typography`, from which the icon inherits `--eds-typography-icon-size`.
3. The dynamic fallback of `1.5em`, which scales with the surrounding `font-size`.

## Accessibility

- An icon without a `title` is decorative and is marked `aria-hidden="true"`.
- An icon with a `title` is semantic. It renders `role="img"` and is labelled by that title.
- Icon-only interactive controls take their label on the control itself rather than on the icon. See `Button` for that pattern.

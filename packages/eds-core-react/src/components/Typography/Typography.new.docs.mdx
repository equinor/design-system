> **Deprecated.** `TypographyNext`, `Heading`, and `Paragraph` are a transitional API from the data-attribute era and are not the target approach for EDS 2.0. Use CSS-first typography instead — see the [Foundation Typography](/docs/eds-2-0-beta-foundation-typography--docs) docs.

These components remain available while existing consumers migrate. They will be removed in a future major version.

## EDS 2.0 approach: CSS-first typography

EDS 2.0 applies typography through CSS tokens and semantic HTML, not wrapper components. Add the `@equinor/eds-core-react/next` CSS bundle to your app and use plain `h1`–`h6` and `p` tags inside a `.eds-elements` container:

```html
<div class="eds-elements">
  <h1>Page title</h1>
  <p>Body copy — correct size, weight, and spacing come from the stylesheet.</p>
  <h2>Section heading</h2>
  <p>Another paragraph.</p>
</div>
```

```tsx
import '@equinor/eds-core-react/next/index.css'
```

Spacing between adjacent block elements (headings and paragraphs) is provided by the flow spacing rules in `elements.css`. You do not need `gap`, `margin`, or wrapper components to get vertical rhythm.

For inline text with explicit token control, use CSS custom properties directly on any element:

```css
.my-label {
  font-family: var(--eds-typography-ui-body-font-family);
  font-size: var(--eds-typography-ui-body-md-font-size);
  line-height: var(--eds-typography-ui-body-md-line-height-squished);
}
```

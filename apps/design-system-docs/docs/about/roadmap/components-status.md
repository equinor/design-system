The maturity of each EDS 2.0 component. EDS 2.0 is in beta, so components marked
<StatusChip status="beta" /> are safe to adopt while the API may still change.

This table is maintained by hand from the EDS Core Components Figma file while
the automated status pipeline is being set up.

- <StatusChip status="planned" /> — on the roadmap, not started
- <StatusChip status="in-progress" /> — being designed or built
- <StatusChip status="beta" /> — shipped in `@equinor/eds-core-react/next`, safe to adopt, API may change
- <StatusChip status="stable" /> — graduated out of beta, API frozen
- <StatusChip status="deprecated" /> — scheduled for removal

_Last updated: 26 October 2026._

## Working on now

What the team is actively building this quarter.

- **Redefined token foundations**: Publishing the new colour, typography,
  spacing, sizing, elevation and theming tokens as the canonical source of
  truth.
- **Token migration and adoption**: Migrating the first component groups onto
  the new token foundations as the reference implementation.
- **Expanding the component ecosystem**: Delivering more web and mobile
  component groups, each with documentation, Figma updates and quality
  assurance.

## Next

Work we expect to pick up soon.

- **AI-assisted design and development**: Making components, documentation and
  patterns easy for people and AI tools to discover, understand and use.
- **Adoption and community engagement**: Growing awareness and trust in EDS
  through outreach, feedback loops, adoption insights and roadmap transparency.

## Exploring

Beyond the current quarter, our direction is shaped by the same themes above:
completing the mobile rollout, moving the remaining component groups onto the
new token foundations, and supporting broader adoption of the EDS 3.0.0 beta
across Equinor. These are intentionally high level. We will firm them up into
dated milestones as the current work lands.

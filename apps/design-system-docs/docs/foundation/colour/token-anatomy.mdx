This page exists to exercise the diagram, not to teach anything. Each figure below is rendered from
its bindings alone, so what the leaders point at and what the specimen paints cannot disagree.

Colour mode shows the token name and its part only. The resolved value is left out on purpose: a
colour resolves to an oklch string, which tells the reader nothing the swatch does not. Spacing and
typography mode print their values, because a length or a weight is worth reading off the diagram.

points at the padding in spacing mode and at the type in typography mode. Switch density to see the
values, the strips and the dots move together.

## Cases the six worked examples do not cover

### An underline colour of its own

A bound `textDecorationColor` brings the underline with it, so the specimen shows the token doing
something rather than sitting inert.

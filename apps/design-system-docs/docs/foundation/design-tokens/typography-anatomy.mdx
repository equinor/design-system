This page exists to exercise the diagram, not to teach anything.

Typography mode uses the same point geometry as colour mode. What it adds is the resolved value on
each row: the family name, the weight, and the font size and line height in pixels. Switching
density below changes the size and line height without any of the token names changing, which is
the whole point of naming a step rather than a number.

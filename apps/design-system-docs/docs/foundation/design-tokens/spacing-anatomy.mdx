This page exists to exercise the diagram, not to teach anything.

In spacing mode the tinted regions are sized from the same custom property the element is padded
with, so they match it exactly without anything being measured. Switching density below moves the
regions, the leader dots and the resolved values together, because all three come from the one
declaration.

The gap region is the exception. Where it falls depends on how wide the child before it is, so its
leader is measured after layout and stays hidden until it has a position.

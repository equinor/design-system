**Comfortable** column is what you get with no `data-density` attribute set.

## Family and weight

These do not change with density. A family resolves to its typeface followed by a generic family,
which the browser uses when the font has not loaded.

| Token                | CSS custom property        | TypeScript          | Value                 |
| -------------------- | -------------------------- | ------------------- | --------------------- |
| `font-family.header` | `--eds-font-family-header` | `fontFamily.header` | Equinor, sans-serif   |
| `font-family.ui`     | `--eds-font-family-ui`     | `fontFamily.ui`     | Inter, sans-serif     |
| `font-family.mono`   | `--eds-font-family-mono`   | `fontFamily.mono`   | CommitMono, monospace |
| `font-weight.normal` | `--eds-font-weight-normal` | `fontWeight.normal` | 400                   |
| `font-weight.medium` | `--eds-font-weight-medium` | `fontWeight.medium` | 500                   |
| `font-weight.bold`   | `--eds-font-weight-bold`   | `fontWeight.bold`   | 700                   |

## In TypeScript

The tokens also ship as TypeScript objects, for the places a CSS custom property cannot reach. A
name segment that starts with a digit becomes a word, and a hyphenated segment is camel-cased, so
`typography.header.2xl.line-height` is `typography.header.twoXl.lineHeight`.

```ts
import { theme } from '@equinor/eds-tokens/next/ts/light-comfortable'

theme.typography.label.md.fontSize // 14
theme.typography.header.twoXl.lineHeight // 32
theme.fontWeight.medium // 500
```

The `next/` paths are temporary for the beta line. Three differences from the CSS form, all easy
to miss:

- **The values are unitless numbers, not lengths.** `14`, not `14px`. Add the unit yourself.
- **A family is the typeface alone.** `theme.fontFamily.mono` is `'CommitMono'`, where
  the CSS custom property is `CommitMono, monospace`. Add the generic family yourself.
- **The density is part of the file name.** There is no attribute for an object to read, so each
  density has its own file, and you pick one:

```ts
import { theme } from '@equinor/eds-tokens/next/ts/light-compact'

theme.typography.label.md.fontSize // 12
```

The family and weight tokens are the same in every file, because they do not change with colour
scheme or density.
